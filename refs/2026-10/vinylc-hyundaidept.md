## D. 디자인 결정과 근거 (Why)

> 이 카드의 핵심. '확정' = 페이지 본문에 근거가 적혀 있음 · '추정' = 근거 문장이 없어 Claude가 추론함.

| 결정 영역 | 무엇을 결정했나 | 왜 (근거) | 근거 수준 |
|---|---|---|---|
| 콘셉트 | HYPER CONNECTED — 오프라인 → 온라인 → 고객 → 다시 오프라인 선순환 | 백화점이 '라이프 공간'으로 바뀌는 흐름, 다변화된 콘텐츠를 쉽게 탐색 | 확정 |
| UI 형태 | 스퀘어 UI | 더현대가 추구하는 '공간'을 시각화 | 확정 |
| 이미지·타이포 | 풀 블리드 이미지 + 미니멀 타이포로 대비 극대화 | 오프라인 공간의 시원한 공간감을 온라인에서 느끼게 | 확정 |
| 강약 | 목록은 스퀘어 UI로 일관, 포커스 콘텐츠 페이지는 과감한 타이포·여백 | 콘텐츠 페이지에서 '또 다른 공간감'을 시각화 | 확정 |
| 템플릿 | 지점 유형별 템플릿 일원화, 대표 지점(더현대)만 인터랙션으로 차별화 | 핵심 정보 접근성 + 아이덴티티가 강한 지점에서만 몰입 경험 | 확정 |
| 가이드 운영 | 디자인 가이드를 최소화하고 요소별 역할을 명확히 | 한 단계 정제된 디자인, 직관적인 정보 제공 | 확정 |
| 정보 구조 | 구조 단순화 | 고객의 주 목적(정보 탐색, 오프라인 연결)을 방해하지 않게 | 확정 |
| 채널 | PC/Mobile Web 유기적 UI 가이드 | 채널에 구애받지 않는 일관된 경험 → '통합 아카이브' | 확정 |

## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 배경 | 백화점이 쇼핑 공간에서 여가·콘텐츠를 체험하는 **'라이프 공간'** 으로 바뀌는 흐름 |
| 콘셉트 키워드 | **HYPER CONNECTED** — 오프라인 공간 → 온라인 공간 → 고객 → 다시 오프라인으로 이어지는 선순환 구조 |
| 디자인 콘셉트 | 더현대가 추구하는 공간을 시각화한 **스퀘어 UI**. 풀 블리드 이미지 + 미니멀 타이포로 대비를 키워 '시원한 공간감'을 표현 |
| 강약 조절 | 목록·탐색 화면은 스퀘어 UI로 일관되게, 포커스가 필요한 콘텐츠 페이지는 반대로 **과감한 타이포와 여백**으로 다른 공간감 |
| 템플릿 전략 | 지점 유형별 템플릿을 하나로 통일해 핵심 정보 접근성↑. 단, 대표 지점 '더현대'만 **인터랙션으로 차별화** |
| 정보 구조 | 디자인 가이드를 최소화하고 요소별 역할을 명확히. 정보 탐색과 오프라인 연결에 방해되지 않게 구조 단순화 |
| 채널 | PC/Mobile Web 유기적 UI 가이드 → 채널에 구애받지 않는 '통합 아카이브' |

**우리 작업에 가져갈 생각법**
- 콘셉트 키워드 하나(HYPER CONNECTED)가 구조(선순환 다이어그램) → 시각(스퀘어 UI) → 템플릿 전략까지 관통합니다.
- **"평소엔 통일, 대표 지점만 특별하게"** — 모든 페이지를 화려하게 하지 않고 차별화할 한 곳을 정합니다. 공공기관 시안에서도 메인·대표 서비스만 연출하고 나머지는 템플릿으로 가는 근거가 됩니다.

## B. 결과물 분석

| 관점 | 관찰한 것 | 왜 효과적인가 |
|---|---|---|
| 첫 화면 | 풀 블리드 계절 비주얼(일러스트·사진) + 큰 카피("에너지 가득, 봄이 피어나다"), 오른쪽에 세로 'THE HYUNDAI' 로고 타이포 | 잡지 표지처럼 계절감·공간감을 먼저 전달 |
| 지점 페이지 | 지점명 + 'DEPARTMENT STORE' 영문 큰 제목, 영업시간·주차 정보, 하단 콘텐츠 카드 | 템플릿 통일로 어느 지점이든 같은 위치에서 정보를 찾음 |
| 더현대 서울 | 'SOUND OF THE FUTURE' 외곽선+채움 혼합 대형 타이포, 건물 사진 위 텍스트 | 대표 지점만 다른 연출로 브랜드 이미지 강화 |
| 시각 | 흑·백·회색 중심 + 강조색 초록(#309069 계열)·연분홍, 정사각 모서리, 굵은 선 아이콘 | 미니멀해서 사진이 주인공이 됨 |
| 멤버십 | 등급별 색이 다른 카드(초록·남색·주황 등)를 가로로 나열 | 등급 차이를 색으로 즉시 인지 |

## 가져갈 패턴

- **콘셉트 키워드 하나로 전 과정 관통** (기획) — 4개 바이널씨 사례 공통
- **콘셉트 다이어그램 한 장** — 원·화살표로 구조를 시각화해 콘셉트 설명을 대신 (새 패턴 후보)
- **세로로 세운 초대형 외곽선 타이포 + 사이사이 화면 배치** — 브랜드명을 그래픽 요소로 (새 패턴 후보, `대형 타이포 구간` 레시피와 연결)
- **평소엔 템플릿, 대표 한 곳만 연출** (기획) — 시안 범위를 정할 때 근거로
- **브랜드 형태 모티브 → UI 시스템**(스퀘어 UI) — 롯데홈쇼핑 L 스퀘어, 신한알파 α와 같은 계열
