## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 슬로건 | **Global Top Tier Player** · 키 카피 "Beyond Limits, Towards Innovation" |
| Brief | 변화하는 글로벌 시장에 대응, 선도 기업의 혁신 가치를 직관적으로 |
| Concept | 핵심 가치 **'글로벌 성장 · 혁신 · 지속가능성'** 3개를 중심으로 브랜드 메시지와 비즈니스 정보를 **스토리텔링 기반**으로 시각화 |
| 구조 | 심플한 메뉴 + **고정형 GNB**, 스크롤 애니메이션·인터랙션으로 몰입 |
| 미디어 | 미디어 메뉴 전면 개편 — **보도자료와 SNS 콘텐츠를 통합**한 디지털 허브 |
| 시스템 | 서체 Figtree + Pretendard, 텍스트 스타일(Headline 1~3, Title…), 3D 반투명 아이콘 세트 |

**우리 작업에 가져갈 생각법**
- 핵심 가치 3개를 메인 스크롤의 **챕터 3개**로 씁니다(스토리텔링 스크롤).
- **보도자료 + SNS 통합 미디어 허브** — 뉴스·보도 목록과 SNS 채널을 따로 두는 기관·기업 사이트에 응용.

## 가져갈 패턴

- **핵심 가치 3개 = 메인 스크롤 챕터 3개** (기획) — `콘셉트 키워드 하나로 관통`의 변형
- **보도자료 + SNS 통합 미디어 허브** (새 패턴 후보) — 공공·기업 사이트
- **브랜드 3D 비주얼 에셋** — KEPCO와 같은 계열(같은 에이전시)
- **사선 화면 콜라주** — 페이지 여러 장을 기울여 깔기
