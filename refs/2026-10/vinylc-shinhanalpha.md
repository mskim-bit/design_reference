## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 출발 질문 | **"분산되어 있는 투자 정보들은 어떻게 어디서 찾아야 하는가?"** — 질문 하나로 프로젝트를 시작 |
| 포지셔닝 | '알아서 챙겨주는 취향 존중 투자 메이트' |
| 구조 원칙 | 논리적·체계적 위계, 시각적 노이즈 최소화, 명확한 대비로 핵심을 빠르게 인지 |
| 개인화 | **장 시작 전 / 거래 중 / 종료 시점** 타임라인별로 필요한 정보를 홈에 자동 제공 → 사용자가 직접 설정하던 수동 홈에서 탈피 |
| 정보 열람 | 모듈·레이어·화면 확장 등 여러 View type으로 탐색 시간 단축 |
| 신뢰·소셜 | 같은 종목 보유자끼리 인사이트를 나누는 '신한투자자' 탭, 타사 보유 종목도 조회 |
| 비주얼 | 어려운 금융 상품을 **정제된 톤의 3D 스타일**로 시각화, 마이크로 인터랙션, **고정폭 숫자 폰트**로 수치 인지 |
| 장기 관점 | 초보도 결국 익숙해지므로 **사용자 유형별로 플랫폼을 나누지 않고 하나의 플랫폼**에서 모두 쉽게 |

**우리 작업에 가져갈 생각법**
- 프로젝트를 **질문 한 문장**으로 시작합니다. 현행 진단의 '개선 목표'를 질문 형태로 쓰는 것도 방법입니다.
- **시간 맥락(언제 쓰는가)에 따라 첫 화면을 바꾸는** 개인화. 공공기관이라면 시즌(신고 기간, 분배 시기 등)에 따라 메인 우선순위를 바꾸는 제안으로 응용할 수 있습니다.
- "사용자 유형별로 나누지 않는다"는 결정. '사용자 집단별로 메인을 갈라 주는' 설계와 반대 관점이라, 사용자 분기를 할지 정할 때 비교해 볼 가치가 있습니다.

## B. 결과물 분석

| 관점 | 관찰한 것 | 왜 효과적인가 |
|---|---|---|
| 홈 | 자산 총액을 크게, 수익률 빨강·파랑, 파란 CTA 띠 | 핵심 수치 하나에 시선 집중 |
| 화면 구조 | Grouping Area / Top Area / Module Area로 영역을 나눈 설계(레이어 분해 그림으로 설명) | 공통 모듈 기준이 명확해 화면이 늘어도 일관됨 |
| 3D | 파란 반투명 3D 아이콘(상자·동전·차트·로봇·손), 브랜드 로고 α도 3D | 금융의 딱딱함을 부드럽게, 톤 통일 |
| 색 | 신한 파랑 단일 강조 + 흰·연보라 회색 바탕 | 수치 색(빨강·파랑)과 브랜드 파랑이 섞이지 않게 관리 필요 |
| 숫자 | 고정폭 숫자 폰트 | 가격·수익률 자릿수가 흔들리지 않음 |

## 가져갈 패턴

- **레이어 분해 다이어그램** — 화면을 기울여 층별로 띄우고 영역 이름을 라벨링. 시안 보고서에서 '화면 설계 원칙'을 설명할 때 (새 패턴 후보)
- **정제된 3D 아이콘 세트(브랜드색 반투명)** — 딱딱한 업종(금융·공공)을 부드럽게. 단, 직접 만든 3D는 '퀄리티 부족'으로 반려된 이력이 있으므로(공유 가이드 6-10) **전문 3D 소스가 있을 때만** (새 패턴 후보)
- **시간 맥락별 첫 화면** (기획) — 시즌·시간대에 따라 메인 우선순위 변경
- **질문 한 문장으로 시작** (기획) — `콘셉트 키워드 하나로 전 과정 관통` 레시피와 연결
- **고정폭 숫자 폰트** — 수치가 많은 화면(통계·회계 공개)에 (기본기)
