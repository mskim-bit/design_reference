## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 리서치 | 사용성 테스트(UT), 포커스 그룹(FGI), 심층 인터뷰로 쇼핑 패턴 발견 — **리서치가 수행 범위에 명시된 유일한 사례** |
| 문제 | '미디어 채널' 인식은 크지만 모바일 고도화가 필요. TV 보던 고객이 폰으로 바로 사는 흐름이 약함 |
| 콘셉트 키워드 | **PIN POINT UX** — 쇼핑 여정에서 구매 확신까지 '콕 짚어주는' 경험 |
| 내비게이션 개편 | 홈 상단의 가변 매장 20여 개 → 발견된 패턴에 따라 **목적별 특화매장 5개**(투데이 / 플레이온 / 트렌드 / 특가 / 랭킹)로 재편 |
| 핵심 기능 | 상하로 나뉘어 있던 실시간 미디어 구조를 단순화하고, **하단 바 중앙에 '방송 구매'** 배치. PIP 모드로 방송 보며 탐색, 숏폼 소비 패턴 반영 |
| 아이덴티티 | 롯데홈쇼핑 **L 그래픽의 스퀘어를 모티브**로 혜택·쇼핑 정보를 확장하는 시스템. L 스퀘어 변형으로 정보 가독성도 높임 |
| 디테일 | 상품 모듈 일관화 + 혜택 강조, 구매 확신을 돕는 마이크로 인터랙션 |

**우리 작업에 가져갈 생각법**
- "메뉴 20개 → 목적 5개"처럼 **리서치에서 발견한 사용 목적으로 메뉴를 다시 묶는** 사례. 현행 사이트 진단의 '정보 구조' 개선 근거로 쓰기 좋습니다.
- 가장 중요한 행동(방송 구매)을 **하단 바 정중앙**이라는 가장 강한 자리에 둡니다.
- 브랜드 로고의 형태(L)를 UI 그리드 단위로 씁니다.

## 가져갈 패턴

- **글자 사이에 이미지를 끼운 문장 타이포** — 문장 속 단어 자리에 작은 사진을 넣어 흐르게. 캠페인 카피·컨셉서 표지에 (새 패턴 후보, `대형 타이포 구간` 레시피와 연결)
- **목적별 메뉴 재편(20 → 5)** (기획) — 리서치로 발견한 사용 목적으로 메뉴를 다시 묶기
- **핵심 행동을 가장 강한 자리에** (기획) — 하단 바 중앙
- **UI 조각 흩어놓기 그리드** — 격자 위에 배지·타이머·토스트 등 작은 UI를 떼어 배치해 디테일을 보여줌 (더현대Hi '튀어나온 정보 카드'와 같은 계열)
- **브랜드 형태 모티브 → UI 시스템**(L 스퀘어)
