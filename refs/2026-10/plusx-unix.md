## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 배경 | 1978년 헤어드라이어로 시작한 40여 년 브랜드. 기술력은 있으나 **'유닉스다움'을 떠올릴 정의가 없음** → BX(브랜드 정체성)부터 재정립 |
| 슬로건 | **"The New Breath of Everyday" / 매일에 새로운 숨결을 더하다** |
| 리서치 | **실무진 인터뷰** → 소비자 · 운영 · 브랜드 **세 관점**의 요구를 인용문으로 정리: "쉽고 빠르게 원하는 제품을 찾게" / "운영을 고려한 체계적 구조" / "올드한 이미지를 탈피하고 모던하게" |
| 디자인 원칙 | 세 관점에 1:1로 대응 — **명확하고 직관적인 / 유연하고 확장되는 / 조화롭고 질서있는** |
| 시각 시스템 | 브랜드 컬러 + 지정 서체(PP Pangram Sans + Pretendard) + **제한된 그리드 시스템** |
| 콘텐츠 | 제품 나열 대신 **일상과 연결된 콘텐츠**(제품이 필요한 순간, 스타일 콘텐츠)를 편집 레이아웃으로 → 구매 동기 유발 |
| 페이지 구조 | 각 페이지 상단에 설명 + 이미지 **커버 영역 고정**, 브레드크럼으로 탐색 혼선 최소화. 메뉴에 연상 이미지 |
| 키 비주얼 | **'숨결'을 그라데이션 톤**으로 — 밝은 → 어두운 톤으로 스며들듯, 마이크로 스크롤링으로 몰입 |

**우리 작업에 가져갈 생각법**
- 요구를 **관점별 인용문(소비자·운영·브랜드)** 으로 적고, 디자인 원칙을 관점 수만큼 1:1로 만듭니다. 공공기관이라면 '이용자·운영 담당자·기관' 세 관점으로 그대로 응용할 수 있습니다.
- 브랜드 키워드(숨결)를 **색 처리 방식(그라데이션)** 으로 번역합니다. 형태 모티브가 아니라 '질감 모티브'.

## C. 케이스 스터디 연출

| 순서 | 구간 | 연출 |
|---|---|---|
| 1 | 히어로 | 흰 바탕에 **"The New Breath of Everyday"** 얇은 초대형 영문을 단어 단위로 흩어 배치, 상단 세로선·메타 |
| 2 | 방향(DIRECTION) | 손에 든 회색 책자 사진 + 세 관점 인용문 목록 |
| 3 | 원칙·시스템 | 색 칩 → 진행선 타임라인 → 서체 두 종(PP Pangram Sans / 프리텐다드) 견본 |
| 4 | 솔루션 콘텐츠 | 모바일 화면을 가운데 세우고 좌우 콘텐츠 카드 |
| 5 | 브랜드 그라데이션 | 은색 그라데이션 대형 이미지 + 단계별 그라데이션 썸네일 5개 |
| 6 | 모바일 콜라주 | 인물 사진 배경 위 화면 카드 여러 장 |

**기술**: 독립 HTML(GSAP + ScrollTrigger + Swiper), 영상 11개. 길이 약 22,500px.

## 가져갈 패턴

- **관점별 인용문 → 1:1 디자인 원칙** (새 패턴 후보, 기획) — 레이지나잇의 '질문 3개'와 같은 계열: **리서치 결과를 3개로 압축해 해결 구간과 1:1로 잇기**
- **질감 모티브(그라데이션)로 브랜드 키워드 번역** — `브랜드 형태 모티브 → UI 시스템`의 변형
- **페이지 상단 고정 커버 + 브레드크럼** — 하위 페이지 템플릿 기본기
- **흩어 배치한 얇은 영문 슬로건 히어로** — `대형 타이포 구간` 레시피
