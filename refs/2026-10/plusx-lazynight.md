## D. 디자인 결정과 근거 (Why)

> 이 카드의 핵심. '확정' = 페이지 본문에 근거가 적혀 있음 · '추정' = 근거 문장이 없어 Claude가 추론함.

| 결정 영역 | 무엇을 결정했나 | 왜 (근거) | 근거 수준 |
|---|---|---|---|
| 추천 | 활동 데이터 기반 추천 영역을 곳곳에 + 팁 문구 | 인터뷰: 새 브랜드를 스스로 찾진 않지만 신뢰하는 추천은 수용 | 확정 |

| 감도 | 레이지나잇만의 무드와 감도를 서비스 곳곳(검색·버튼·필터)에 | 인터뷰: 잘 쓰는 커머스엔 그 서비스만의 경험 포인트가 있음 | 확정 |
| 통합 | 29CM와 중복 기능을 하나로(29+1 = One) | 통합 목적, 더 넓은 고객층에 다양한 상품 | 확정 |
| 톤 | 따뜻한 회베이지 + 얇은 대형 영문 | 'Have a Lazy Evening' — 한가한 저녁의 여유로운 무드(근거 문장 없음) | 추정 |

## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 배경 | 무신사가 40~50대 여성용으로 출시 → 연령을 허물고 고감도 서비스로. 29CM와 통합(중복 기능을 하나로: '29+1 = One') |
| 브랜드 정의 | **"Have a Lazy Evening"** — 한가한 저녁에 트렌드를 소비하며 취향을 넓히는 플랫폼 |
| 리서치 | Client Needs(브랜드 → 고객 소통) + User Interview("새 브랜드를 스스로 찾진 않지만 신뢰하는 추천은 수용", "요약된 콘텐츠 선호") |
| **핵심 발견 → 질문 3개** | 01 Curation: 신뢰할 수 있는 추천이 되려면? / 02 Organizing: 다양한 콘텐츠를 잘 정리해 전달하려면? / 03 Lazymood: 레이지나잇만의 색다른 쇼핑 포인트는? |
| 목표 | 발품 없이 취향에 맞는 브랜드를 찾게, 제공자가 아니라 **사용자와 연관된 콘텐츠를 요약**해서 |
| 해결 1 | **related to my taste** — 활동 데이터 기반 추천 영역을 곳곳에 + 팁 문구("좋아하는 아크네 스튜디오와 비슷한 브랜드") |
| 해결 2 | **rules of Content Organization** — 콘텐츠 유형을 컴포넌트화해 한눈에 파악 |
| 해결 3 | **Lazy Mood** — 레이지나잇의 무드와 감도를 서비스 곳곳(검색·버튼·필터)에 |

**우리 작업에 가져갈 생각법**
- 인터뷰 결과를 **'어떻게 하면 ~할까?' 질문 3개**로 바꾸고, 각 질문에 이름(Curation/Organizing/Lazymood)을 붙여 해결 구간의 제목으로 그대로 씁니다. 문제 → 해결이 1:1로 보입니다.
- 추천에 **팁 문구(왜 추천했는지)** 를 붙여 신뢰를 만듭니다.

## C. 케이스 스터디 연출

| 순서 | 구간 | 연출 |
|---|---|---|
| 1 | 히어로 | 회베이지 바탕에 그림자 진 폰 사진, 상단 3단 메타(플랫폼 설명 / 프로젝트명·연도 / PLUS X) |
| 2 | 통합 다이어그램 | 29cm + LAZYNIGHT → Merger 29+1 → One |
| 3 | 콘셉트 | **"Have a Lazy Evening"** 얇은 초대형 영문 + 시계 모티브(L·N·3) |
| 4 | 리서치·질문 | 인터뷰 인사이트 → 번호 붙은 질문 3개 |
| 5 | 해결 구간 | 각 구간을 **"related to my taste" "rules of Content Organization"** 같은 초대형 영문 제목으로 시작 |
| 6 | 화면 | 폰 3대 나란히, 컴포넌트 조각, 풀 블리드 패션 사진 |
| 7 | 타이포 | Light / Regular / Bold 굵기 칩 |

**기술**: 독립 HTML(GSAP + ScrollTrigger), 영상 16개, 이미지 184개. 길이 약 44,600px.

## 가져갈 패턴

- **인사이트 → 이름 붙은 질문 3개 → 해결 구간 제목** (새 패턴 후보, 기획)
- **추천 이유 팁 문구** — 개인화 영역의 신뢰 장치 (새 패턴 후보)
- **얇은 초대형 영문 구간 제목** — `대형 타이포 구간` 레시피(타 에이전시 사례 추가)
- **통합 다이어그램(A + B → One)** — `콘셉트 다이어그램 한 장`과 같은 계열
