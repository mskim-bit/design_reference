## A. 프로젝트 접근 방식

| 단계 | 내용 |
|---|---|
| 슬로건 | **KEPCO TOMORROW** (페이지 상단에 흐르는 띠 문구로 반복) |
| 원칙 1 · 디자인 시스템 | **KRDS(한국형 웹 콘텐츠 디자인 시스템 계열 정부 가이드)와 웹접근성 심사기준을 100% 준수** → 디지털 취약계층까지 고려한 포용적 디자인 |
| 원칙 2 · 비주얼 아이덴티티 | 국내외 브랜드 포지셔닝 분석 → 글로벌 리더십 방향. 주요 콘텐츠를 **일관된 3D 비주얼 에셋**으로 시각화 |
| 원칙 3 · 서비스 흐름 | 사이트별로 나뉘어 있던 회원정보를 **통합 로그인**으로 일원화. 오래 운영되며 제각각이 된 고객소통 메뉴 UX를 통일 |
| 구조 | 한전 서비스 생태계를 **Tier 1 / Tier 2 동심원 지도**로 정리(한전ON, KEPCO PLUS 앱, 사이버지점 등) |
| 그리드 | 정보성 페이지 Column 12 / Gutter 16px / Margin Auto 등 **페이지 유형별 그리드 명세** |

**우리 작업에 가져갈 생각법**
- 공공 사이트는 **"기준 준수"를 디자인 원칙 1번**으로 둡니다. KRDS·웹접근성 준수를 제약이 아니라 강점(포용성·품격)으로 표현.
- 흩어진 사이트·앱을 **동심원 생태계 지도**로 먼저 정리한 뒤 통합합니다. 하위 서비스가 많은 기관(신탁자·거래처·자료실 등)에 그대로 응용 가능.
- 화려한 비주얼은 **메인 키 비주얼(3D)** 에 집중하고, 정보 페이지는 엄격한 그리드로.

## C. 케이스 스터디 연출 (더즈 공통 형식)

| 순서 | 구간 | 연출 |
|---|---|---|
| 1 | 제목 | 파란 바탕에 "한국전력공사"(채움) + "통합 디지털 플랫폼"(외곽선) — **한 줄 안에서 채움/외곽선 대비** |
| 2 | 기기 영상 | 어두운 계단 위에 노트북·태블릿·폰 목업 |
| 3 | 메인 화면 | 아이맥·노트북 목업이 겹쳐진 큰 이미지 |
| 4 | 생태계 지도 | 동심원 Tier 다이어그램 |
| 5 | 사옥 사진 + 흐르는 띠 | "KEPCO TOMORROW" 무한 반복 대형 텍스트 |
| 6 | 원칙 텍스트 3개 + 영상 | 글로벌 지구 3D 영상, 그리드 명세 영상 |
| 7 | 앱 | 3D 아이콘 + 화면 수십 장 콜라주 |

**기술**: WordPress + Elementor, **Locomotive Scroll**(콘텐츠 통째 이동), jQuery·Swiper. 길이 약 15,300px.

## 가져갈 패턴

- **정부 기준 준수를 디자인 원칙 1번으로** (기획, 공공) — 공공기관 시안 보고서에 바로 적용
- **서비스 생태계 동심원 지도** (새 패턴 후보) — `콘셉트 다이어그램 한 장` 계열
- **페이지 유형별 그리드 명세** — `디자인 시스템 노출` 레시피 사례
- **브랜드 3D 비주얼 에셋** — 키 비주얼·아이콘을 같은 톤 3D로 (새 패턴 후보)
- **흐르는 슬로건 띠** — `대형 타이포 구간`(키네틱) 사례
- **채움/외곽선 대비 제목** — 더즈 케이스 스터디 공통 (`대형 타이포 구간`)

## 피할 것

- 3D 영상 키 비주얼은 용량이 커서 공공 사이트 첫 로딩·저사양 환경을 고려해야 함(정지 이미지 대체·정지 버튼)
- 팀 피드백 금지 목록의 '흰 외곽선 글자' — 외곽선은 장식 제목에만
