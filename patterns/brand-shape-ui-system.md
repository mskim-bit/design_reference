# 브랜드 형태 모티브 → UI 시스템

- 한 줄 정의: 로고·공간의 형태(정사각, L, α 등)를 UI 그리드·배지·카드 모양의 기본 단위로 삼아 화면 전체에 브랜드를 심는다.
- **용도: 시안 화면(B).** 로고·공간 형태를 UI 단위로.
- 상태: 정착 후보 — 출처 2곳(바이널씨 3 · 플러스엑스 1: plusx-unix '숨결'을 그라데이션 질감으로 — 형태 대신 **질감 모티브**)
- 등장 사례: vinylc-hyundaidept(더현대 공간 → 스퀘어 UI), vinylc-lottehomeshopping(L 로고의 스퀘어 → 라이브 배지·혜택 그래픽), vinylc-shinhanalpha(α 로고 → 3D 오브젝트·아이콘 톤)

## 언제 쓰나
- 로고나 공간에 뚜렷한 형태가 있을 때. 색만으로 브랜드를 표현하기 약할 때

## 구현 요점
- 형태 1개를 정하고 쓰임을 3곳 이하로 제한(카드 모서리, 배지, 강조 그래픽)
- 보고서에 "로고 형태 → UI 적용 예" 대응표를 넣는다

## 자주 하는 실수
- 모티브를 모든 요소에 적용해 과해짐
