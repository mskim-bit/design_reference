# 콘셉트 키워드 하나로 전 과정 관통 (기획 패턴)

- 한 줄 정의: 리뉴얼의 목표를 키워드·질문 하나로 압축하고, 그 키워드가 정보 구조 → 시각 언어 → 기능 우선순위까지 이어지게 설계한다.
- **용도: 기획(A).** 키워드를 화면에 크게 써 붙이는 게 아니라 구조·시각·기능 결정의 근거로 씁니다.
- 상태: **유행중** — 출처 3곳(바이널씨 4 · 플러스엑스 3 · 더즈 3)
- 더즈 사례: does-kepco("KEPCO TOMORROW"), does-ktng(핵심 가치 3개 = 스크롤 챕터 3개), does-pompidou(방문 전후 여정을 하나로)
- 플러스엑스 사례: plusx-kolonmall(전략 4단어 Straightforward/Discovery/Context/Engagement), plusx-lazynight("Have a Lazy Evening"), plusx-unix("The New Breath of Everyday")
- 처음 기록: 2026-10 · 등장 사례: refs/2026-10/vinylc-thehyundaihi.md("발견형 큐레이션 몰"), vinylc-hyundaidept.md("HYPER CONNECTED"), vinylc-lottehomeshopping.md("PIN POINT UX"), vinylc-shinhanalpha.md("분산된 투자 정보를 어디서 찾아야 하는가?")

## 언제 쓰나 / 언제 피하나
- 쓰기 좋은 곳: 리뉴얼 시안의 첫 보고, 컨셉서 표지, 시안별 '해결한 문제점' 정리
- 피할 곳: 키워드가 화면에 실제로 반영되지 않을 때(구호만 남음)

## 구조
1. 현행 진단의 핵심 문제 → **키워드 1개** 또는 **질문 1문장**
2. 키워드 → 정보 구조(예: 발견 / 큐레이션 / 나의 공간 3축, 메뉴 20개 → 목적 5개)
3. 키워드 → 시각 언어(예: 공간감 → 스퀘어 UI + 풀 블리드)
4. 키워드 → 가장 강한 자리에 둘 기능(예: 하단 바 중앙 '방송 구매')

## 구현 요점
- 시안 보고서에 "키워드 → 구조 → 시각 → 기능" 표를 한 장으로 넣는다.
- 키워드는 영문 대문자 슬로건이든 한국어 정의든 상관없지만, **화면 근거가 3개 이상** 있어야 한다.

## 자주 하는 실수
- 키워드를 여러 개 만들어 흐려짐 → 하나만
- 키워드와 무관한 연출을 끼워 넣음
