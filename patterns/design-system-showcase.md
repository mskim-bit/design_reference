# 디자인 시스템 노출 (색 칩 · 아이콘 그리드 · 컴포넌트 변형)

- 한 줄 정의: 결과 화면 뒤에 색 칩, 아이콘 키라인 그리드, 반응형 카드 변형을 보여줘 시스템의 완성도를 증명한다.
- **용도: 보고서·컨셉서 전용(C)** — 사이트 화면에는 넣지 않습니다.
- 상태: **유행중** — 출처 3곳(바이널씨 4 · 플러스엑스 3 · 더즈 3: kepco 페이지 유형별 그리드 명세, pompidou 그리드 수치+서체+색, ktng 텍스트 스타일+3D 아이콘)
- 등장 사례: vinylc-thehyundaihi(색 칩 + 아이콘 그리드 + 배너 변형), vinylc-hyundaidept(색 칩 + 아이콘), vinylc-lottehomeshopping(카테고리 아이콘), vinylc-shinhanalpha(3D 아이콘 + 레이어 분해)

## 언제 쓰나
- 시안 보고서·컨셉서 마지막 장, 피그마 이관 전 시스템 공유

## 구조
색 칩(이름 + HEX) → 타이포 단계 → 아이콘(키라인 그리드 위 큰 아이콘 1 + 세트) → 컴포넌트 변형(같은 카드의 크기별 모습)

## 구현 요점
- 색은 **이미지가 아니라 텍스트로 HEX를 적는다**(바이널씨는 이미지라 측정 불가 — 반면교사)
- 시안에서 토큰을 CSS 변수로 쓰고 있다면 그 값을 그대로 노출

## 자주 하는 실수
- 실제 화면에 안 쓰인 색·아이콘까지 늘어놓음
